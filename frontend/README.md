# Apex frontend

React 18 + TypeScript + Vite UI for:

- explicit constellation-scoped planning;
- owner/operator constellation asset management;
- zero-account synthetic conjunction replay;
- provided-Pc and covariance quality explanations;
- hypothetical before/after planning impact;
- JSON/Markdown evidence export.

For the supported zero-configuration experience, run `make demo` from the
repository root and open http://localhost:5173.

Local frontend development:

```bash
npm ci
npm run dev
npm run lint
npm run test
npm run build
```

`VITE_API_BASE_URL` defaults to `http://localhost:8000`. The Phase 0 UI is a
decision-workflow demonstration, not an operational SSA or maneuver system.
