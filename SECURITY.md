# Security policy

## Supported versions

Until the first stable release, only the latest tagged pre-release is supported.

## Report a vulnerability

Use GitHub private vulnerability reporting. Do not include vulnerabilities, secrets,
restricted CDM, credentials, or personal data in a public issue.

Include:

- affected tag or commit;
- reproduction steps using synthetic data;
- impact and affected trust boundary;
- suggested mitigation, if known.

The project aims to acknowledge reports within three business days. This is a
best-effort open-source target, not a guaranteed SLA.

## Safety boundary

Apex is research and decision-support software. It is not flight-certified, does not
send commands, and must not be the sole basis for a maneuver decision.
