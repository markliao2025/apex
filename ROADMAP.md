# Apex public roadmap

The current public milestone is Phase 0 only. See
[`docs/build-in-public/PUBLIC_ROADMAP.md`](docs/build-in-public/PUBLIC_ROADMAP.md)
for the six-week artifact and validation cadence.

## Now: Phase 0

- Make the existing constellation planner scoped, deterministic, and explainable.
- Let a new user run the synthetic conjunction replay without private keys.
- Keep provided Pc, missing covariance, and hypothetical planning impact visibly separate.
- Publish reproducible evidence artifacts and collect observable workflow behavior.

## Gate before Phase 1

Phase 1 does not begin until the six complete calendar-week Gate in
[`PHASE0_AI_EXECUTION_PLAN.md`](PHASE0_AI_EXECUTION_PLAN.md) passes. Stars,
maintainer test runs, automation, and generated feedback do not count.

## Explicitly later

- Phase 1: versioned OMM/CDM import and independently computed Pc, only with
  supported covariance/reference frames and golden validation.
- Phase 2: transparent event trends and policy-level mitigation candidates.
- Phase 3: a bounded Ops Copilot over typed, deterministic tools and human approval.

No phase authorizes autonomous maneuver execution or describes Apex as
flight-certified.
