# ADR-0001: Apache License 2.0

Status: accepted for Phase 0  
Date: 2026-07-24

## Decision

License Apex source code under Apache License 2.0 and use Developer Certificate of
Origin 1.1 sign-offs for contributions.

## Rationale

Apache-2.0 supports commercial and research adoption, includes an explicit patent
grant, and does not require copyright assignment. Data and third-party assets keep
their own terms and are not relicensed by this decision.

## Consequences

- Every public distribution includes `LICENSE` and `NOTICE`.
- Contributors sign commits with `Signed-off-by`.
- Assets without proven redistribution rights are excluded from releases.
- The project name and marks are not granted by the software license.
