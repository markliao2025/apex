# Public roadmap

| Week | Tagged scope | Validation question |
| --- | --- | --- |
| 1 | `v0.0.1` zero-config synthetic replay | Can a new user reach and explain the replay? |
| 2 | `v0.0.2` constellation-scoped planning impact | Does the before/after view match a real planning decision? |
| 3 | `v0.0.3` data-quality explanation | Which missing information blocks trust? |
| 4 | `v0.0.4` evidence export and provenance | Would this artifact be shared in a review? |
| 5 | `v0.0.5` errors and setup repair | What prevents self-serve adoption? |
| 6 | `v0.0.6` evidence summary only | GO, ITERATE, PIVOT or STOP EXPANSION? |

Dates begin only when `v0.0.1` is publicly available and the clean Quickstart
passes on a Docker-capable host. Future tags are not promises to add capability;
they may remove or clarify misleading behavior based on evidence.
