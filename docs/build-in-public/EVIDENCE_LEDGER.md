# Public evidence ledger

Start this ledger only after `v0.0.1` is publicly available and a clean Docker
Quickstart has passed. Each row must link to a public Issue, Discussion, or pull
request. Do not copy personal information or private correspondence into this
file.

| Date (UTC) | Week | GitHub handle | Evidence level | Public link | Counted Gate behavior | Maintainer decision |
| --- | ---: | --- | --- | --- | --- | --- |

Evidence levels:

- E0: view, star, like, or share. Record separately; never count toward the Gate.
- E1: an independent user completed Quickstart.
- E2: structured workflow feedback.
- E3: replay of the user's own public, synthetic, or shareable event.
- E4: the same user returned at least seven days later.
- E5: an external test vector, adapter, or pull request.

One person can create several rows, but Gate totals must deduplicate participants
and clearly distinguish first use from repeat use. Maintainer runs, automation,
and AI-generated feedback do not count.
